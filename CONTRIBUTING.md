# Contributing

Lemon is a private, single-maintainer fork — there's no open call for contributions, no public issue tracker, and
no community to route pull requests through. If you've found this repository, feel free to read the code, but
there's no contribution process to follow here.

## Credit where it's due

Lemon exists because of [Eden](https://git.eden-emu.dev/eden-emu/eden) and, before it, yuzu, and the broader
community of Switch emulator forks that kept development going after yuzu's shutdown. All the actual emulation
work — the CPU JIT, the GPU renderer, the HLE services, all of it — is theirs. This fork only changes what gets
built, how, and the Android app's branding/UX around it. See [README.md](./README.md#special-thanks) for the full
list.
