# Independent Emulator Project Direction

This branch is being developed toward an independently branded Android emulator project, using Lemon Project as an initial codebase foundation. This does not claim the emulation engine is written from scratch yet.

## Target device
- Infinix Hot 50 4G
- MediaTek Helio G100
- Mali-G57 MC2
- 8 GB RAM

## Development goals
1. Establish independent application identity, package, UI, and project documentation.
2. Inspect and map the existing codebase before changing engine components.
3. Preserve license notices and comply with upstream license requirements.
4. Build a modular architecture for device profiles, graphics configuration, diagnostics, and emulation backend.
5. Implement changes only where source files and compatibility requirements are verified.
6. Set up reproducible Android builds and CI.
7. Validate install, launch, configuration, library management, and backend behavior on supported hardware.

## Current status
Planning and repository documentation only. Source tree inspection, code modifications, APK builds, and device testing are pending access to the source files and build environment.
